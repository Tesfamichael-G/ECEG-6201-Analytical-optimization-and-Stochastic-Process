# Solutions

Key steps and final answers for the tutorial problems at the end of each chapter.
The chapter's **worked examples** contain full derivations; these pages give the
essential steps and the numeric answers so you can check your work as you go.

!!! tip "Use sparingly"
    Do the problem first, then read the solution. Reading a solution before
    attempting the problem wastes the learning opportunity — the struggle is
    where the understanding forms.

---

## How each solution page is organised

Every page mirrors its chapter:

- **One section per tutorial problem** — same numbering as in the chapter.
- **Key steps** in 2–6 lines — enough to follow the argument, not to replace it.
- **Final answer** in bold — so the check is instantaneous.

If a step is unclear, follow the **"See Example N.M"** link back to the
chapter, where the derivation is worked out in full.
